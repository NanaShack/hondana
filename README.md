# 私の本棚

スマホで使う蔵書管理アプリです。バーコードを読み取って本を登録し、未読・読書中・読了を管理します。

## 機能

- **バーコードで追加**：カメラを本の裏表紙に向けるだけでISBNを読み取ります。続けて何冊でも登録できます
- **書誌情報の自動入力**：ISBNから書名・著者・出版社・表紙を [openBD](https://openbd.jp/)（なければ Google Books）で取得します
- **検索・絞り込み・並び替え**、シリーズごとのまとめ表示（読了の進み具合つき）
- **新刊チェック**（`shinkan.html`）：本棚の作家の新刊・発売予定を [国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/) で調べ、持っていない本だけを一覧にします。シリーズの続きには印がつきます
- **バックアップ**：JSON / CSV で書き出し・取り込み
- **オフライン対応**：ホーム画面に追加するとアプリのように使えます

## データの保存場所

蔵書データはこのリポジトリには含まれず、**使っている端末のブラウザの中だけ**に保存されます。

- iPhone では Safari の共有メニューから「ホーム画面に追加」して、そこから開いてください（Safari のタブのまま使うと、長期間開かなかった場合にデータが消えることがあります）
- 機種変更や誤削除に備えて、メニュー（右上の「…」）からときどきバックアップを書き出してください
- 新しい端末では、メニューの「ファイルから取り込む」でバックアップを読み込めます

## 構成

ビルド不要の静的サイトです。GitHub Pages でそのまま公開できます。

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `shinkan.html` / `shinkan.js` | 新刊チェック |
| `sw.js` / `manifest.webmanifest` | オフライン対応とホーム画面用の設定 |
| `zxing.min.js` | バーコード読み取りライブラリ [ZXing](https://github.com/zxing-js/library) 0.21.3（Apache License 2.0、`zxing-LICENSE`） |

アプリを更新したときは `sw.js` の `VERSION` を上げると、端末側のキャッシュが入れ替わります。

## 新刊チェックのしくみ

- フォロー中の作家ごとに国立国会図書館サーチの検索API（OpenSearch）を呼び、直近4か月と発売予定の紙の本を集めます
- 図書館のサーバーに負担をかけないよう、1人ずつ順番に問い合わせ、結果は端末に3日間保存して使い回します
- 最初は本棚に2冊以上ある作家をフォローします。画面右上の「作家」から変更できます
